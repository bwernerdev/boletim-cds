# imagens/

Imagens fixas do boletim, extraídas do `.docx` original e convertidas para `.webp`: personagens com 440 px de altura, as demais reduzidas. O nome do arquivo (sem extensão) é a chave usada em `app/conteudo.js`.

Depois de incluir ou trocar um arquivo aqui, rode `python ferramentas/gerar_imagens_js.py` para atualizar `app/imagens.js`.

| Arquivo | Uso |
| --- | --- |
| `morlus.webp` | Personagem Morlus (abertura, congelamento, HUB, encerramento) |
| `borba.webp` | Borba, gerente regional (média, OP-294, inventários, evolução) |
| `lechinski.webp` | Lechinski (HUB) |
| `ezequias.webp` | Ezequias, CD Cabo Sto Agostinho (BSC) |
| `arailton.webp` | Arailton, CD Aquiraz (BSC, ajustes) |
| `leonardo.webp` | Leonardo, CD Cambé (devoluções) |
| `cleia.webp` | Cleia, CD Salvador (regularização de compras) |
| `paulo.webp` | Paulo, CD Nova Santa Rita (XML) |
| `valeria.webp` | Valéria, CD Duque de Caxias (Quirius) |
| `controladoria.webp` | Logo Controladoria Administrativa CDs (capa) |
| `seara.webp` | Logo Seara (capa) |
| `prevencao.webp` | Logo Prevenção de Perdas (reserva, não usado ainda) |
| `goal.webp`, `escada.webp`, `alerta.webp`, `inventario.webp`, `trofeus.webp` | Ilustrações ao lado dos títulos das seções |
| `setas.webp` | Ilustração de evolução (reserva, não usada ainda) |
