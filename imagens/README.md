# imagens/

Imagens fixas do boletim, extraídas do `.docx` original e convertidas para `.webp`: personagens recortados nas bordas e com até 640 px de altura, as demais reduzidas. O nome do arquivo (sem extensão) é a chave usada em `app/conteudo.js`.

Depois de incluir ou trocar um arquivo aqui, rode `python ferramentas/gerar_imagens_js.py` para atualizar `app/imagens.js`.

| Arquivo | Uso |
| --- | --- |
| `morlus.webp` | Morlus (abertura, congelamento dia a dia, HUB, encerramento) |
| `borba.webp` | Borba, gerente regional (média, OP-294, inventários, evolução) |
| `lechinski.webp` | Lechinski (HUB) |
| `ezequias.webp` | Ezequias, CD Cabo Sto Agostinho, barba grisalha (ajustes) |
| `arailton.webp` | Arailton, CD Aquiraz, de terno (BSC) |
| `leonardo.webp` | Leonardo, CD Cambé (devoluções) |
| `cleia.webp` | Cleia, CD Salvador (regularização de compras) |
| `paulo.webp` | Paulo, CD Nova Santa Rita (XML) |
| `valeria.webp` | Valéria, CD Duque de Caxias (Quirius) |
| `controladoria.webp` | Logo Controladoria Administrativa CDs (cabeçalho das folhas) |
| `seara.webp` | Logo Seara (cabeçalho das folhas) |
| `prevencao.webp` | Logo Prevenção de Perdas (cabeçalho das folhas) |
| `goal.webp`, `escada.webp`, `alerta.webp`, `inventario.webp`, `trofeus.webp` | Ilustrações clarinhas no canto das seções (marca d'água) |
| `setas.webp` | Ilustração de evolução (reserva, não usada ainda) |
